# HeadsetBar

Заряд беспроводных наушников, мыши и клавиатуры прямо на панели задач Windows, слева от системного трея.

## Возможности

- Встраивается в панель задач и сдвигается левее, если место занято другим виджетом.
- Значок устройства, батарейка и процент. Анимация при зарядке, красный цвет при 20% и ниже.
- По клику открывается панель: все устройства, их состояние, автозапуск и выход.
- Обновляется сразу при подключении и отключении устройств.
- Светлая и тёмная темы, разные масштабы экрана.
- Не требует прав администратора, не выходит в интернет и не собирает данные.

## Установка

1. Скачайте `HeadsetBarSetup.exe` со страницы **Releases**.
2. Запустите и нажмите «Установить».

Файл без цифровой подписи, поэтому Windows может показать «Система Windows защитила ваш компьютер». Если вы доверяете этому проекту, нажмите «Подробнее» → «Выполнить в любом случае». Можно также собрать программу самому из исходников (см. ниже).

Удаление: «Параметры» → «Приложения» → HeadsetBar.

**Требования:** Windows 11 или Windows 10 (1809 и новее), .NET Framework входит в систему. Поддержка Windows 10 проверена только на макете панели задач, не на самой системе.

## Поддерживаемые устройства

| Устройство | Процент | Зарядка | Проверено на устройстве |
|---|---|---|---|
| Мыши VXE / ATK / VGN (USB 373B и 3554) | Да, оценка по напряжению | Да | Одна мышь: донгл 373B:1085, кабель 3554:F58F |
| Bluetooth-устройства, заряд которых знает Windows | Да | Нет | Нет |
| HyperX Cloud II Wireless, Cloud Alpha Wireless | Да | Да | Нет |
| SteelSeries Arctis 7 | Да | Нет | Нет |
| SteelSeries Arctis 7+, Nova 5, Nova 7 | Да (на части моделей с шагом 25%) | Да | Нет |
| Corsair, семейство Void | Да | Да | Нет |
| Logitech G PRO / PRO X Wireless, G535 | Да | Да | Нет |
| Ajazz AK820 (0C45:8009, донгл 0C45:FDFD) | Нет, клавиатура не передаёт | Только «на кабеле» | Да |

Проверили на своём устройстве или его нет в списке? Создайте Issue и укажите модель, VID и PID.

## Ограничения

- Процент мыши — сглаженная оценка: меняется не быстрее 1% в минуту, чтобы не прыгать при подключении зарядки.
- Спящее устройство нельзя отличить от выключенного: через 20 секунд без связи значок становится серым и без процента.
- Виджет показывается только на основном мониторе. Вертикальная панель Windows 10 поддерживается.

## Сборка

Нужна только Windows: используется компилятор из состава .NET Framework.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт запускает тесты и создаёт `dist\HeadsetBarSetup.exe`.
